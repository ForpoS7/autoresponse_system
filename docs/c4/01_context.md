# C4 Level 1 — System Context

Показывает систему целиком и её отношения с внешним миром.

```mermaid
C4Context
  title System Context — HH AutoResponse System

  Person(user, "Соискатель", "Хочет автоматически откликаться на релевантные вакансии HH.ru")

  System(hh_auto, "HH AutoResponse System", "Парсит вакансии, генерирует сопроводительные письма и отправляет отклики на HH.ru от имени пользователя")

  System_Ext(hh_ru, "HH.ru", "Платформа поиска работы. Источник вакансий и цель для откликов")
  System_Ext(ollama, "Ollama (qwen2.5:7b)", "Локальный LLM-сервер. Генерирует персонализированные сопроводительные письма")

  Rel(user, hh_auto, "Запускает автоотклик, отслеживает статус", "HTTPS / JSON")
  Rel(hh_auto, hh_ru, "Парсит вакансии, отправляет отклики", "Playwright / Browser")
  Rel(hh_auto, ollama, "Запрашивает генерацию письма", "HTTP / Kafka")

  UpdateLayoutConfig($c4ShapeInRow="3", $c4BoundaryInRow="1")
```

## Ключевые решения

| Аспект | Решение |
|---|---|
| Взаимодействие с HH.ru | Playwright (браузерная автоматизация) — сайт не имеет публичного API |
| Генерация писем | Ollama локально — без внешних API-ключей и платежей |
| Пользователь | Один соискатель = один аккаунт HH.ru; токен хранится зашифрованно |
